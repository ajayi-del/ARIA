# CEO Grading Law (operator directive 2026-09-06: every CEO correction
# becomes skill law)

The CEO (claude-opus-5, 2 sessions/day) grades the firm's learning objects.
These corrections are permanent doctrine — apply them BEFORE the CEO has
to issue them again.

## 1. The verification contract (§4, unchanged since M9)
Every shipped repair is verified by an independent node: (1) read the diff
+ check tier limits, (2) run the pins yourself, (3) independently recompute
the headline from raw data (never self-certify — the CEO re-ran the
576-cell golden against the TRUE pre-change code at 9e6fe97, not against
our claim), (4) append a register status line. **Reported done and
unverified within 48h = NOT VERIFIED, and it blocks the next commission.**

## 2. n counts DISTINCT POSITIONS, never records
Shadow gates firing from a fast loop deduped per (symbol,direction,gate)/
1800s let ONE position contribute ~48 records/day and reach n>=30 alone.
Serially correlated repeats of one decision are not 30 observations.
Every graduation bar, every gate-accuracy n, every shadow cohort: count
distinct entry_ids. Amended on both D11 gates; binding on all future
gates at birth.

## 3. Pin the domain expansion, not just the happy path
A change applied BEFORE a None-returning guard expands the function's
return domain: D11's ATR floor flipped 210 of 360 grid cells None -> live
stop, and that class (a TIGHTENING legacy declined) was unpinned and
un-scored by the shadow gate. When a fix touches code upstream of a guard:
enumerate the legacy-None cells, pin the intended behavior there too, and
say explicitly whether the new returns are measured.

## 4. NOT GRADABLE doctrine
A grade computed over a contaminated window or from an unrepaired
instrument reports NOT GRADABLE — never RED, never a knob. A gate flagged
pre-repair vetoes any proposal citing its output on sight (gate-accuracy
circularity ban). D10 gate-econ plane mismatch: until #24 lands, no knob
touches counter_trend or quiet_market_pause — an unmeasurable gate makes
any change unfalsifiable.

## 5. Liquidity-control your own headline before publishing
The CEO halved its own selection-skill headline (8.85x -> 3.6-3.9x): the
vol_z denominator collapses on thin symbols, so the "skill" was half
thinness artifact. Before any lift/edge number leaves the building, run
the obvious confound control against your own result (liquidity band,
regime split, day-type split), declare the slice count (Aronson bound),
and publish the controlled number as THE number. 0.00x at >=$2M/hr is
also the finding: 10% moves don't happen in deep names.

## 6. Shared-memory write hygiene (D8 byte law)
ceo_directives.md sits inside Cato's argv against a ~120k tripwire.
**HARD CAP 5KB, permanent.** It grew 5,434 -> 12,552 bytes on two
unbounded Governor appends (projection ~116.5k). The pattern is: archive
verbatim to ~/aria_ceo/memory/archive/, rewrite the live file compact
(fold settled items into one-line CLOSED entries carrying a pointer to
the archive), never append-and-leave. Every node reports its injected
bundle size each cycle. Applies to any file injected into another node's
prompt (watchdog memory, handover, mission).
